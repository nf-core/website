We support using AI (i.e., LLMs) as tools for coding.
However, you remain responsible for any code you publish and we are responsible for any code we merge and release.

## Code

If you’re using AI tools, try to stick by these guidelines:

- Keep PRs as small and focussed as possible
- Avoid any unnecessary changes, such as moving or refactoring code (unless that is the explicit intention of the PR)
- Review all generated code yourself before opening a PR, and ensure that you understand it
- Engage with the community review process and expect to make revisions
- Do not flood repositories with many PRs or Issues

_The nf-core community members reserve the right to reject contributions that do not meet our guidelines_

## Communication

To maintain the strongly people-centric and friendly atmosphere of the community, we encourage you to communicate with the community in your own words, that includes the content of GitHub issues and pull requests as well as on chat platforms such as Slack.
_People generally like to communicate with humans, not robots_.

**If you are opening an issue**, we prefer you to describe the problem in your own words.

**If you are opening a pull request**, we expect you to be able to explain the proposed changes in your own words.
This includes the pull request body and responses to questions.
Do not copy responses from the AI when _replying to questions_ from maintainers.

We understand that AI is useful when communicating as a non-native English speaker.
If you use AI to avoid language barriers, please make sure the output reflects your own ideas.
If you wish to include context from an interaction with AI in your issue and pull request descriptions and comments:

- Disclose that you used AI to write the text
- We suggest must be in a quote block (e.g., using `>`) and disclosed as such.
- Tell your LLM to reduce verbosity as far as possible ([example skill](https://gist.github.com/bavanws/123e0343f8a79cec825d9141124a0a83))

Following these guides will make your interactions with a wider portion of community more friendly and productive.

_This policy is derived from an [earlier statement](https://nf-co.re/blog/2026/statement-on-ai) from the nf-core core team in January 2026._
